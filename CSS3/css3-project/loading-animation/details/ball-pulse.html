CSS 样式

详见仓库内 loader-awesome/css/ball-pulse.css（已经是完整可复用样式）。

使用说明

  1. 在 <head> 中引入 CSS：
    <link rel="stylesheet" href="loader-awesome/css/ball-pulse.min.css">
  2. 在页面中使用对应的 HTML 结构（见下方代码）。
  3. 可选尺寸修饰类：.la-sm（小）、.la-2x（2 倍）、.la-3x（3 倍）。
  4. 可选主题修饰类：.la-dark（深色），或在元素上设置 color 自定义颜色。
